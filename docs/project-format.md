# 项目格式 v1：主体 + 底座

机器定义见 [project.schema.json](../schema/project.schema.json)，运行时验证见 `src/model.js`。

```json
{
  "version": 1,
  "subject": { "shape": "heart", "scale": 0.84, "x": 0.5, "y": 0.5 },
  "base": {
    "preset": "paper", "mat": 24, "shadow": false,
    "background": { "src": "./background.jpg", "focusX": 0.5, "focusY": 0.5 }
  },
  "settings": {
    "template": "mosaic", "ratio": "portrait", "gap": 0,
    "padding": 60, "columns": 4, "seed": 233, "showHeader": false,
    "title": "", "subtitle": "", "eyebrow": "", "signature": "",
    "showCaptions": false
  },
  "images": [
    { "id": "film-1", "title": "作品名", "src": "./posters/one.jpg", "focusX": 0.5, "focusY": 0.35 }
  ]
}
```

`images` 必填。`subject`、`base`、`settings` 及其字段均可省略。未知字段不参与渲染，并在标准化保存时移除。

## 拼贴主体

| 字段 | 值 / 含义 | 默认 |
|---|---|---|
| subject.tileRatio | 网页固定模板：portrait 2:3、landscape 3:2、square 1:1；native 仅供 Agent 自定义与旧项目 | native |
| subject.crop | 是否明确允许将单张原图裁切到 tileRatio；不裁切拼贴外轮廓 | false |
| subject.shape | square 方形、portrait 竖长方形、landscape 横长方形、heart 心形、circle 圆形、arch 拱形 | square |
| subject.scale | 0.3–1，占可用空间的比例 | 0.82 |
| subject.x / y | 0–1，在可用空间中从左到右 / 从上到下的位置；网页显示 0–100%，50% 居中，并可一键复位两轴 | 0.5 |
| subject.granularity | 1–4 整数，尺寸层级：1 / 2 / 3 / 4 种固定高度，原字段名保留兼容 | 1 |
| subject.count | 固定模板的精确档位张数，最多 200；native 仍接受 1–600 的密度预算；也可为 null | null |
| subject.repeat | 是否允许复用素材，布尔值 | false |
| settings.template | 旧字段，仅保留导入兼容，不再影响排列 | mosaic |
| settings.gap | 旧字段，接受 0–32；当前渲染统一无缝，忽略此值 | 0 |
| settings.columns | 旧字段，仅保留导入兼容，层级排版自动决定列数 | 4 |
| settings.seed | 0–4294967295 整数，固定拼贴布局 | 233 |

主体形状独立于成品比例：例如 4:5 底座中可以放方形、横幅或心形。主体保持比例；可用空间自动扣除边距、托纸、相框和已启用的文字区域。位置为边界对齐系数，0 靠左 / 上，1 靠右 / 下。主体占满相应轴时，该轴位置不产生位移。

心形使用宽高约 1.12:1 的圆润轮廓，两侧对称，顶部浅凹，底部自然收尖。各层级共用轮廓，边缘依然由完整矩形图片拼成。

所有主体由矩形图片拼成，不使用轮廓遮罩。默认保留原图全貌；网站的固定模板要求素材符合选定比例，否则提示用户更换比例或主动开启 subject.crop。crop 只裁切单张图片以填满固定格子，不剪裁拼贴外轮廓。心形、圆形、拱形通过图片位置形成阶梯状外轮廓；矩形按固定层级组合完整图片。关闭重复时，每张选中的图片出现一次，互不重叠。

层级固定为 1–4。网页模板严格使用 N 种离散尺寸，整张拼贴只做一次统一缩放；尺寸之间的比例由模板决定，不进行连续微调。同档图片宽高完全一致。网页每个项目使用一种图片比例，横竖混合素材须明确开启裁切。随机分组、同宽堆叠和素材分配只能使用这些档位，不能再次拉伸行或图片。导出取整可能出现 1 像素差，不能把它视为新档位。

native 自由模式开启重复时，按素材原始比例建立对称列网格，轮廓只决定哪些完整格子参与拼贴。在相同比例的相邻格子中合并 2×2、3×3、4×4 的块，内部尺寸交错，不改变外轮廓。心形左右对称，圆形上下、左右对称，图片本身不翻转。超过 10 种不同比例、网格不足等情况采用紧密条带布局。

native 自由模式关闭重复时，心形使用成对肩部和居中主体；圆形用成对条带与居中一行不成对的素材。图片数量或对称配对不足时 native 模式的实际层级可能减少；网页不提供此模式。不隐式复用、不裁切、不拉伸。少量素材或混合很多不同比例会限制轮廓和错落效果；矩形外沿允许有阶梯，内部依然相接，不通过留白凑尺寸。

图片统一无缝拼接，旧 settings.gap 字段仍能读取，但不参与渲染。导出时公共边缘对齐输出像素，心形以同一条像素中轴取整两侧，圆形沿水平和垂直两条像素中轴取整，避免透明底上的细线。

网页方形、横幅、竖幅使用严格齐边且比例准确的预生成矩形模板。固定模板由 npm run build-templates 生成；数量不兼容时给出提示，网页只提供可用数量档位，不偷偷改变层级。关闭重复时使用前 N 张素材，其余素材保留。

「海报数量」与「层级」独立。固定网页模板的每组形状／图片比例／层级提供 6 个精确容量，数量不超过 200，尽量覆盖个位数或十几张到接近 200 张。`fixedQuantityOptions(subject)` 返回可用容量；渲染必须匹配目录中的实际张数，不再近似预算。1 层的少数矩形组合例外：竖／横版素材拼方形、方形素材拼竖／横幅只有 6、24、54、96、150；竖版素材拼横幅、横版素材拼竖幅只有 36、144，优先保持完整原图、固定大小和精确外框。

所有数量始终显示，素材不足且未允许重复时置灰；允许重复只解锁，不改变档位或选择。关闭重复后若已选张数超出素材数量，保留选择并显示缺少素材的提示。null 选择不超过素材数的最大档；没有可用档时选最小档并提示。切换形状／图片比例／层级或导入旧网页项目时，过时容量映射到可用档位。native 自定义模式继续接受 1–600 的预算（不保证精确张数），null 在重复时为 216、不重复时为全部素材。成品画布尺寸仍由成品比例决定。

网页复用与布局分开分配：数量低于素材总数时只使用前 N 张；超出素材总数时，每张素材至少出现一次，使用次数最多相差 1。优先分散同一封面，避免相邻重复、长条连排及集中在大图位置。seed 固定布局变体与分配顺序。native 模式保留原有按比例分组规则。素材列表、ID 和可移植文件中只保留一份原图，其余素材不会删除。空素材仍为空画布。固定模板 CLI 示例：`--tile-ratio portrait --shape square --levels 4 --count 80 --repeat`（旧名 `--granularity` 仍可用；比例不兼容时可明确加 `--crop`）。

网页「换一版」更新 seed 和素材顺序，并支持撤销。项目保存后随机结果固定，网页与 CLI 使用同一配置可重现。

native 自定义模式的轮廓随图片数量与比例变化；关闭重复时，少量图片只能形成简化轮廓，1 张图片保持完整矩形。关闭重复且没有相同比例的素材可配对时，心形采用居中的简化轮廓，无法形成完整双肩；不会为此复用或裁切素材。主体包围盒是最大可用范围，实际拼贴按原图比例适应其中，不会为填满包围盒拉伸图片。旧排列和胶片装饰已停用，旧 template / columns 字段仍能读取。

## 底座

| 字段 | 值 / 含义 | 默认 |
|---|---|---|
| base.preset | none 无底座、white 白卡、paper 纸张、black 黑卡、gallery 细框 | white |
| base.mat | 旧项目固定托纸宽度，0–80 基准像素；网页不再提供滑块，新项目用 subject.scale 调整留白 | 0 |
| base.shadow | 主体 / 托纸投影，布尔值 | false |
| base.background | null 或图片对象（src、focusX、focusY，可选 id、title） | null |
| settings.padding | 成品外侧最小留白，16–100 基准像素 | 48 |
| settings.ratio | portrait 1080×1350、square 1080×1080、story 1080×1920、landscape 1920×1080 | portrait |

`base.preset: "none"` 表示无底座，PNG 的空白区与图片间隙保留透明。此时忽略托纸和投影，标准化时将 `base.background` 置为 null；网页隐藏相关控件，导出格式固定 PNG，CLI 使用 JPG 会报错。预览棋盘格只用于显示透明区域，不写入图片。成品比例、主体大小、位置与外侧留白仍然生效，透明文件仍保留完整画布尺寸。

背景图采用 cover 填满底座；背景对象不计入拼贴素材数量。自定义背景与预设托纸 / 相框可以组合：JSON 中同时指定 `base.background` 和 `base.preset`。网页上传背景会保留托纸与细框，从「无」上传则切换为白卡；点击另一个预设会清除自定义背景，可撤销。移除背景恢复当前预设。

托纸是拼贴背后的完整矩形。白卡 / 纸张 / 黑卡的托纸使用各自的纯色；细框在成品四周绘制 28 px 深色边框。纸张纹理由固定种子的 Canvas 图形生成，无外部素材依赖。底座和主体是项目中的逻辑图层，最终导出为单张 PNG/JPG。

## 文字与图片

网页已移除文字功能：恢复草稿、导入项目和预览导出时，`showHeader`、`showCaptions` 均关闭，不渲染标题或作品名称，也不预留文字区域。旧文案仍作为项目数据保留。Agent / CLI 可自行使用这些兼容字段；启用 `showHeader` 后，非空的眉题、标题、副标题、落款居中放在主体下方。不自动添加编号、英文页脚或水印。

- `title`、`eyebrow`、`signature`：最多 80 字符；`subtitle`：最多 160 字符。
- `showHeader`、`showCaptions`：布尔值，默认 false。
- 图片 `src` 必填；`id` 最多 100 字符且素材间唯一；图片 `title` 最多 120 字符。缺失 ID 和标题按位置生成。
- 主体默认完整显示。启用 subject.crop 后，`focusX`、`focusY` 控制单张图片的裁切位置（0–1，默认 0.5）。背景图仍使用 cover，0 优先左 / 上边缘，1 优先右 / 下边缘。
- 最多 100 张主体素材，另加一张背景；每张最多 20 MB、6000 万像素。网页导入素材长边缩至 2000 px，背景长边缩至 3840 px。CLI 保留原分辨率。
- 项目 JSON 最多 80 MB。背景和素材均仅支持本地 PNG/JPEG/WebP 或对应 base64 data URL，不访问远程 URL，不接受 SVG。

CLI 的路径相对输入 JSON 目录解析；`--background` 参数相对当前命令目录解析。网页打开外部路径 JSON 时，请将 JSON、所有素材及背景一起拖入，按唯一文件名匹配。网页「保存项目」与 CLI `--project` 均将素材和背景内嵌，可直接重新打开。

输出倍率为 1、2、3，主体、托纸、边距、字体同步缩放。字体来自系统；无中文字体的 CLI 主机可用 `--font` 指定 TTF/OTF/TTC。

## 已有项目

继续接受 version 1 项目。没有两层配置的旧文件会补充默认方形主体、白卡底座；图片、顺序、旧 focus 字段和已填写文字保留，按新的装裱构图重新排版。旧 `settings.theme` 会保留在项目中，新的底座颜色由 `base.preset` 决定。需要旧版完全相同的成图时，请保留旧导出图片。
