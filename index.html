找封面

找到封面，保存图片，再导入素材。

音乐
  • CoverCay ↗搜歌曲、专辑或歌手，选地区与尺寸下载。
  • MusicBrainz ↗选具体发行版 → Cover Art，找正封面。
  • Bandcamp ↗独立音乐、原声与同人专辑，找艺人发行页。
影视
  • TMDB ↗电影、剧集与番剧 → 图片／海报，按语言选图。
  • Fanart.tv ↗补充电影、剧集海报，也能找背景与无字图。
动画
  • Bangumi ↗用中文或原名找动画，也收录书籍、音乐和游戏。
  • AniList ↗用英文或罗马音找番剧，核对季度与剧场版。
游戏
  • SteamGridDB ↗搜游戏 → Grids；竖版可选 600 × 900，也有方形。
  • IGDB ↗补充主机与旧作封面，核对平台及发行版本。
从 Steam 文件夹找

在 Steam 主目录内打开 appcache/librarycache，连同子文件夹查找 library_600x900。自己设置的封面通常在 userdata/<用户编号>/config/grid。

Windows
C:\Program Files (x86)\Steam
macOS
~/Library/Application Support/Steam
Linux / Steam Deck
~/.local/share/Steam

以上为常见位置；自定义安装与 Flatpak 可能不同。缓存只含已加载的图片，文件名和目录会随客户端版本变化；找不到可用 SteamGridDB。

轻小说 / 漫画
  • BOOK☆WALKER 日本 ↗日文原版轻小说、漫画，按书名与卷数找单册。
  • BOOK☆WALKER 台湾 ↗繁中版轻小说、漫画，留意版本与特装封面。
  • KADOKAWA ↗角川官方书目，含电击文库、MF 文库 J 等。
  • 集英社 ↗官方漫画与书籍封面，核对单行本卷数。
书籍
  • 豆瓣读书 ↗搜中文书名或 ISBN，先核对出版社和版本。
  • 博客来 ↗繁中书籍、轻小说与杂志，查看单本商品封面。
  • Open Library ↗用书名或 ISBN 找版本，适合补充外文书。
  • Google Books ↗按书名、作者或 ISBN 查找；部分只有缩略图。
选图与保存
  • 用原名＋年份、卷数或 ISBN，核对语言与发行版本。
  • 进入作品页，优先保存原图或大图；手机可长按。若只有小图，换一个来源。
  • 导入 JPG、PNG、WebP。不要把网页链接或搜索结果缩略图当作原图。
  • 图片版权归原权利人，分享时保留来源；商业使用请核对授权。
